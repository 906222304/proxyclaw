# ProxyClaw frontend

Vue 3 + TypeScript + Vite UI, embedded by `proxyclaw.exe` through WebView2 and
served from `frontend/dist` by the local API server.

## Commands

```bash
npm ci          # install from the lockfile
npm test        # Vitest unit tests (src/**/*.test.ts)
npm run build   # type-check with vue-tsc, then build to dist/
npm run dev     # Vite dev server on http://localhost:5173
```

`src/version.ts` is generated by CMake at configure time. Run a CMake configure
once (or create the file with `export const PROXYCLAW_VERSION = 'dev'`) before
building the frontend on its own.

## Developing against a running backend

Start `proxyclaw.exe` with `PROXYCLAW_DEV_URL=http://localhost:5173`. The
window then loads the dev server through `/api/session`, which Vite proxies to
`127.0.0.1:18080` so the API session cookie is set for the dev origin.

All API calls go through `src/api/client.ts`. Requests rely on the
same-origin session cookie; a 401 means the session ended (ProxyClaw
restarted) and the window must be reopened.

## Stack

- UI components: [reka-ui](https://reka-ui.com/) (shadcn-vue style) + Tailwind CSS 4
- Tables: AG Grid Community
- JSON editor: Monaco, lazy-loaded from `src/lib/monacoRuntime.ts`
- Icons: Lucide
